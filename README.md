# Онлайн тренажер простых арифметических задач

Web-версия: React + TypeScript + Vite.

## iPhone

Нативная версия на SwiftUI находится в [`ios`](ios/README.md).

- Открыть на Mac: `open ios/Arithmetics.xcodeproj`.
- Схема Xcode: **Arithmetics**, минимальная версия iOS 17.
- Четыре действия, короткие и свободные тренировки, офлайн, локальная история.
- [Сборка, тесты и архитектура](ios/README.md).
- [Подготовка публикации в App Store](ios/AppStore/RELEASE.md).

Для публикации требуется Apple Developer Program, подпись своей Team и проверка App Review. Исходники сами по себе не означают, что приложение уже опубликовано.
