# Арифметика для iPhone

Первая нативная версия вашего web-тренажёра на SwiftUI. iOS 17+, iPhone, русский и английский интерфейсы, светлая и тёмная темы. В приложении нет аккаунтов, рекламы, покупок, сервера и сторонних SDK.

## Первая версия

- Сложение с результатом до 20, 100 или 1000.
- Вычитание с числами в выбранном диапазоне и положительным целым ответом.
- Умножение и деление по таблице 1–10; деление без остатка.
- Тренировки на 10, 20 задач или в свободном режиме.
- Цифровая клавиатура, мгновенная проверка, повторная попытка после ошибки.
- Показ ответа учитывается как пропуск.
- Результат: решено, ошибки, пропуски, точность с первой попытки, лучшая серия.
- Сохранение незавершённой тренировки и последних 100 результатов на устройстве.
- Поддержка VoiceOver, Dynamic Type, Reduce Motion. Тренировку можно прокрутить в ландшафтной ориентации.

Диапазон для сложения ограничивает **результат**, а для вычитания — **операнды**. Правильный ответ завершает задачу; кнопка «Следующая задача» исключает случайное повторное увеличение счётчика. Точность рассчитывается по первым попыткам с учётом пропусков. Время результата — время с начала сессии, включая паузы.

## Открыть на Mac

1. Скачайте ветку с iOS-версией или клонируйте её:

   ```bash
   git clone --branch codex/ios-mvp https://github.com/Tosoundra/arithmetics.git
   cd arithmetics
   open ios/Arithmetics.xcodeproj
   ```

2. В Xcode выберите схему **Arithmetics** и симулятор iPhone. Нажмите **⌘R**.
3. Для запуска на своём iPhone добавьте Apple Account в **Xcode → Settings → Accounts**. В **Arithmetics → Signing & Capabilities** выберите свою Team и включите **Automatically manage signing**. При необходимости задайте собственный уникальный Bundle Identifier. Для личного тестирования платное членство не требуется; возможности бесплатной подписи ограничены.
4. Для App Store используйте Xcode 26+ с SDK iOS 26+. Минимальная версия устройства в проекте — iOS 17; это отдельная настройка от версии SDK.

## Проверка

В Xcode: **Product → Test (⌘U)**. Проект содержит unit-тесты и UI-тесты.

Чистая арифметика тестируется без iOS SDK:

```bash
cd ios
swift test
```

Workflow `iOS build and tests` выполняет `swift test`, сборку и тесты в симуляторе, сборку unsigned release archive и сохраняет XCTest-скриншоты. **Unsigned archive нельзя загрузить в App Store**: он нужен для проверки Release-компиляции. Для распространения нужен подписанный архив из вашей Apple Developer Team.

UI-тесты используют отдельное хранилище и фиксированный первый пример; обычные пользователи получают случайные задачи. Тесты проверяют неверный/верный ответ, повторную попытку, все операции, показ ответа, паузу, восстановление после перезапуска и историю.

## Код

| Путь | Назначение |
|---|---|
| `Arithmetics/Core` | Генератор, проверка, состояние тренировки, сохранение |
| `Arithmetics/App` | SwiftUI-экраны и работа с UserDefaults |
| `Arithmetics/Resources` | Иконка, переводы, настройки приложения, privacy manifest |
| `Tests/ArithmeticCoreTests` | Проверка 12 000 задач и переходов состояния |
| `UITests` | Проверка пользовательских сценариев в симуляторе |
| `AppStore` | Тексты карточки и инструкция публикации |

Зависимости приложения отсутствуют. Xcode-проект уже включён. При добавлении файлов его можно заново создать командой `python3 scripts/generate_project.py`. Для изменения иконки используется `scripts/generate_icon.py`; Pillow нужен только для повторной генерации, не для сборки приложения.
