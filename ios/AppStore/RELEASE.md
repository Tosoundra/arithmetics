# Подготовка первой публикации

На этом этапе подготовлены исходники, Xcode-проект, иконка, manifest конфиденциальности, тесты и черновики карточки. Публикация ещё не выполнена. Имя приложения и Bundle ID в проекте — предлагаемые значения; их доступность проверяется в вашем Apple Developer аккаунте.

## 1. Apple Developer

Зарегистрируйтесь в [Apple Developer Program](https://developer.apple.com/programs/enroll/) со своего Apple Account. Apple указывает стоимость 99 USD за год; локальная цена отображается при оформлении. Потребуются проверка личности, принятие соглашения и оплата. Если регистрироваться как физическое лицо, в магазине отображается ваше юридическое имя продавца; для компании условия регистрации отличаются.

После активации проверьте доступ к [App Store Connect](https://appstoreconnect.apple.com/). Пароль и коды подтверждения вводите в интерфейсе Apple, а не в коде или переписке.

## 2. Подпись и приложение

1. Откройте `ios/Arithmetics.xcodeproj` в Xcode 26 или новее. Требование Apple к SDK на дату подготовки: iOS 26+, Xcode 26+.
2. В **Signing & Capabilities** выберите свою Team, включите автоматическую подпись. Предлагаемый Bundle ID: `com.tosoundra.arithmetics`. Убедитесь, что он принадлежит вашей Team; при необходимости замените.
3. В App Store Connect создайте **New App → iOS**. Выберите тот же Bundle ID. Предлагаемый SKU: `arithmetics-ios`. SKU — внутренний идентификатор, не название в магазине.
4. Предлагаемая версия — `1.0.0`, build — `1`. Увеличивайте build при повторной загрузке той же версии.

## 3. Проверить на устройстве

Перед загрузкой выполните **⌘U** и проверьте на реальном iPhone:

- Все четыре операции, диапазоны и завершение тренировки.
- Ошибку, повторный ответ, пропуск, свободный режим.
- Закрытие и повторное открытие приложения во время тренировки.
- Историю, сброс прогресса, светлую/тёмную темы, крупный текст, VoiceOver.
- Режим полёта: тренировка должна работать без сети.

Проверьте скриншоты из CI визуально. Диагностические скриншоты UI-тестов нельзя автоматически считать готовыми материалами магазина.

## 4. Карточка App Store

Тексты находятся в папках `ru` и `en-US`. Это черновики, соответствующие первой версии. Основная категория: **Education**; приложение распространяется бесплатно, без покупок и рекламы. Итоговое имя зависит от доступности в магазине.

Необходимые данные владельца, которые нельзя вывести из кода:

- Copyright — юридическое имя владельца прав и год.
- Контакт для App Review — ваше имя, рабочий email и телефон.
- Территории распространения; статус trader для распространения в ЕС заполняется по вашей ситуации.
- Возрастной рейтинг — ответы по фактическому содержимому. Встроенных чатов, рекламы, пользовательского контента и покупок нет. Категория Kids автоматически не выбирается.
- Цена и доступность — выберите бесплатное распространение для первой версии либо измените решение перед отправкой.

**App Privacy:** для текущей реализации ожидаемый ответ — **Data Not Collected**, поскольку результаты и настройки обрабатываются локально и не передаются разработчику. Если появятся аналитика, реклама или сервер, пересмотрите декларацию. `PrivacyInfo.xcprivacy` содержит причину `CA92.1` для UserDefaults.

В репозитории есть `public/ios/privacy.html` и `public/ios/support.html`. После принятия PR существующий workflow Pages может разместить их вместе с web-приложением. Используйте фактический URL успешного Pages deployment и обязательно проверьте обе страницы. **Пока PR не принят и deployment не прошёл, считать эти страницы опубликованными нельзя.** Можно разместить эти же файлы на другом принадлежащем вам публичном HTTPS-сайте. Support URL должен вести на страницу поддержки, Privacy Policy URL — на страницу политики.

Для iPhone нужны реальные скриншоты приложения в принятых Apple размерах. Проверьте актуальные [Screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications). Сделайте скриншоты главного экрана, задачи и результата для русского и английского интерфейсов. Снимки должны быть без прозрачности и не обещать отсутствующие функции. Эта версия предназначена для iPhone; iPad как отдельная целевая платформа отключён.

## 5. Загрузить и протестировать

1. В Xcode выберите **Any iOS Device (arm64)**, затем **Product → Archive**.
2. В Organizer выполните **Validate App**, затем **Distribute App → App Store Connect → Upload** с вашей Team.
3. Дождитесь обработки build в App Store Connect. Проверьте декларацию экспортного соответствия. В текущем приложении нет собственного шифрования; `ITSAppUsesNonExemptEncryption=false`.
4. Через TestFlight установите сборку на свой iPhone и пройдите основные сценарии. Публичное beta-тестирование для первой версии не требуется.

## 6. Отправить на проверку

Выберите обработанную сборку, заполните карточку, контакты и рейтинг. В Review Notes можно использовать текст из `review_notes.txt`: аккаунт не нужен, вся функциональность доступна офлайн. Для первой публикации удобно выбрать ручной выпуск после одобрения.

Нажмите **Add for Review**, затем **Submit for Review** согласно текущему интерфейсу App Store Connect. После решения Apple устраните замечания или выпустите одобренную версию. Одобрение и срок проверки определяет Apple; наличие исходников не означает успешную публикацию.
